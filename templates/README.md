# Templates

This directory stores the reusable HTML dashboard template and any region patch notes.

## Expected content

- template HTML file from the existing EASO regional dashboard
- region-specific patch notes for DATA, INVERSE, ord, and additional filter injection
- any CSS or JS patch files that are applied to the template

## Design intent

The instruction set explicitly says to reuse the template and patch only a small set of points rather than rebuilding the front end from scratch.
