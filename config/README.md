# Configuration

This directory holds region-specific build parameters and workbook metadata.

## Template

Use [region-template.json](region-template.json) as the starting point for each region build. Populate the country list, short codes, sponsorship flag, and any sub-office rules from the workbook and region launch deck.

## Notes

The instruction file emphasizes that the region roster is a contract to reconcile against the actual workbook columns and not to trust blindly.
